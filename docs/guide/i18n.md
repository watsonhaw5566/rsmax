# 国际化（i18n）

`@rsmax/i18n` 是基于 JS 模块的轻量国际化方案，支持多语言切换、变量插值、嵌套键值，并由编译器实现**按需加载**：只有使用了 `@rsmax/i18n` 的项目才会引入运行时与语言包。

## 目录结构

在项目根目录创建 `locales/`（也支持 `src/locales/`），文件名即语言代码：

```
locales/
├── zh-CN.js
├── en.js
└── ja.js
```

## 创建语言包

语言包通过 `module.exports` 导出嵌套对象，支持点号路径与 `{name}` 插值：

```js
// locales/zh-CN.js
module.exports = {
  app: { name: '我的应用' },
  home: {
    title: '首页',
    greeting: '你好，{name}！',
    items: { count: '共 {count} 条记录' },
  },
  common: { confirm: '确定', cancel: '取消' },
};
```

```js
// locales/en.js
module.exports = {
  app: { name: 'My App' },
  home: {
    title: 'Home',
    greeting: 'Hello, {name}!',
    items: { count: '{count} items total' },
  },
  common: { confirm: 'Confirm', cancel: 'Cancel' },
};
```

## 初始化

在 `app.js` 中设置默认语言与兜底语言：

```js
import { initI18n } from '@rsmax/i18n';

initI18n({
  locale: 'zh-CN',
  fallbackLocale: 'zh-CN',
});

App({
  onLaunch() {},
});
```

## 在页面中使用

```jsx
import { useI18n, t, setLocale } from '@rsmax/i18n';

export default function HomePage() {
  const { locale } = useI18n();

  return (
    <view class="container">
      <text>{t('home.title')}</text>
      <text>{t('home.greeting', { name: 'World' })}</text>
      <text>{t('home.items.count', { count: 10 })}</text>
      <text>{t('common.confirm')}</text>

      <button onClick={() => setLocale('zh-CN')}>中文</button>
      <button onClick={() => setLocale('en')}>English</button>
      <text>当前语言：{locale}</text>
    </view>
  );
}
```

::: warning JSX 中的限制
WXML 模板无法执行 JS 函数，因此 JSX 里的 `t('key')` 会在编译期转换为 <code>&#123;&#123;__i18n['key']&#125;&#125;</code> 数据绑定。这意味着模板中 `t()` 的参数必须是**字符串字面量**，不能是变量或表达式，插值参数也不会在模板中计算。

带变量插值的场景，请在 JS 逻辑中（事件处理函数、`useEffect` 等）调用 `t('key', params)` 计算结果，再通过 `useState` 绑定到视图。
:::

## API

### initI18n(options)

初始化全局 i18n 实例，返回该实例。

```js
initI18n({
  locale: 'zh-CN',      // 默认语言
  fallbackLocale: 'en', // 兜底语言
  messages: {           // 可选：内联消息（无需 locales 文件）
    'zh-CN': { hi: '你好' },
    en: { hi: 'Hello' },
  },
});
```

### useI18n()

在函数式组件 / 页面中调用，返回 `{ t, locale, setLocale, addMessages }`。调用后会：

- 把当前语言的扁平消息注入 `data.__i18n`；
- 订阅语言切换，变化时自动 `setData` 更新视图；
- 页面卸载时自动取消订阅。

### t(key, params?)

翻译函数，支持点号嵌套键与 `{name}` 插值；key 不存在时返回 key 本身。

```js
t('home.title');                      // '首页'
t('home.greeting', { name: '张三' }); // '你好，张三！'
```

在 JS 逻辑代码中作为普通函数正常使用；在 JSX 模板中会被编译为数据绑定。

### setLocale(locale)

切换语言，返回 Promise。切换后所有已挂载组件自动更新。

```js
setLocale('en').then(() => console.log('语言已切换'));
```

### getLocale()

获取当前语言代码。

### addMessages(locale, messages)

动态添加消息（适合从后端拉取语言包）。若添加的是当前语言，会立即触发视图更新。

```js
addMessages('fr', { home: { title: 'Accueil' } });
```

### getI18n() / createI18n(options)

- `getI18n()`：获取全局实例，适合在非组件环境（工具函数）中使用；
- `createI18n(options)`：创建独立的 i18n 实例（高级用法）。

## 按需加载原理

1. **按需检测**：编译每个 JS/JSX 时检测是否引用 `@rsmax/i18n`，未使用则不产出任何 i18n 文件；
2. **路径重写**：`import { t } from '@rsmax/i18n'` 重写为产物内相对路径；
3. **运行时复制**：首次检测到使用时，把运行时复制到产物根目录；
4. **语言包懒加载**：扫描 `locales/` 生成 `rsmax-i18n-locales.js`，每个语言包用函数包裹，只有切换到该语言时才 `require` 对应文件；
5. **WXML 转换**：`t('key')` 转换为 <code>&#123;&#123;__i18n['key']&#125;&#125;</code>。

监听模式下，`locales/` 目录语言包的新增与修改会自动重新生成模块。
